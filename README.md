HitBTC is a cryptocurrency exchange offering spot, margin and futures trading. It publishes a public REST API (v3, with legacy v2) at api.hitbtc.com with market data, spot/margin/futures trading, wallet, sub-account and user-management endpoints, three WebSocket streaming APIs (market data, trading, wallet), HMAC (HS256) and Basic authentication, a demo sandbox at api.demo.hitbtc.com, and a Swagger UI API explorer serving its OpenAPI 3.1 contract.

**Areas:** Company · Cryptocurrency · Cryptocurrency Exchange · Trading · Market Data · Futures · Wallets

## How this profile is made
